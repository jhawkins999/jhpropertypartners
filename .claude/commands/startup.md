Orient a new JH Property Partners session. Run these first, then read, then
confirm the plan with me before doing any work.

1. **Openers.** `git log --oneline -5` and `git status`. Do not touch a file
   until you know where the repo is and what is uncommitted.

2. **Read `CLAUDE.md` in full — starting with the `TOP 12` block at the top.**
   ⚠️ **Most of this file is deliberately UNKNOWN.** That is not an oversight
   and it is not an invitation to fill it in. Fill a section only from what John
   actually says or what is verifiable on the live site.

3. **Read `docs/TODO.md`** (the live checklist) and the last two entries of
   `docs/Session_Log.md`. **Skim `docs/Operator_Observations.md`** — durable
   lessons about GoHighLevel and about verifying work. Note that Section 1 was
   ported from the BizRevGrowth project: it is platform knowledge, not brand
   canon.

4. **Read `docs/GHL_Site_Launch_Playbook.md`** before touching the site. It is
   the repeatable process and it carries the landmine list.

5. **Know the live site.** `jhpropertypartners.com` is a LIVE GoHighLevel site.
   Six real pages: `/`, `/services`, `/testimonials`, `/contact`,
   `/privacy-policy`, `/terms-and-conditions`, plus `/home-750690` which serves
   duplicate homepage content. Baseline state: `docs/Baseline_Audit_2026-08-01.md`.
   When auditing, fetch RAW HTML (Cloudflare caches ~60s), and check desktop AND
   mobile variants.

**Reminders that always apply:**
- **⛔ NEVER use GHL's "Ask AI".** It fabricates content and fabricates status
  reports. Platform property, not a brand rule.
- **Neither BizRevGrowth canon nor Triwise canon governs this project.** Do not
  import their pricing, positioning, banned-word lists, brand palettes, voice
  rules or guarantees. Process discipline ports; content canon never does.
- **Invent nothing.** No testimonials, case studies, claims about the offer, or
  compliance statements that John has not confirmed.
- **This is a real business with real money at stake.** It buys houses for cash.
  Copy that overstates, promises a price, or implies terms is a legal exposure,
  not just bad writing.
- The site is built in GoHighLevel's page builder. Keep every recommendation
  achievable there. **There is no application code in this repo.**
- **BizRevGrowth is the higher priority** unless John says otherwise.
